# OnQ MCP server

The maintained Windows and ChatGPT version is on the [codex/onq-windows branch](https://github.com/nikhil-naran/onq-mcp-server/tree/codex/onq-windows).

Start with that branch's [README](https://github.com/nikhil-naran/onq-mcp-server/blob/codex/onq-windows/README.md), then follow its [Windows setup guide](https://github.com/nikhil-naran/onq-mcp-server/blob/codex/onq-windows/docs/onq/SETUP.md). For an existing Windows installation, use the [update guide](https://github.com/nikhil-naran/onq-mcp-server/blob/codex/onq-windows/docs/onq/UPDATE-WINDOWS.md).

This `master` branch contains the original Claude Desktop prototype and is retained for history. Use `codex/onq-windows` for the current server and tunnel.
