# OnQ for ChatGPT

Personal OnQ adaptation of JhostinAleck’s Brightspace MCP server, with Nikhil’s Queen’s-specific features.

**Start here: [Windows setup](docs/onq/SETUP.md).**

Use an always-on Windows desktop session and OpenAI’s private MCP tunnel. Includes persistent browser login, rubrics, completion status, visual PDF previews and a filtered agenda. LMS writes are disabled in the supplied configuration.

The original README below remains upstream documentation; its upgrade command, general authentication presets and release claims may not describe this fork. No live Windows/Queen’s connection is bundled or claimed.
